Что означает «активных дней»

Количество разных календарных дат, в которые сохранённая проверка подтвердила активное объявление. Это не количество полных суток размещения. Дни между проверками не засчитываются автоматически. Повторное использование снимка не добавляет новый день.

Объявления объединяются по подтверждённому unique_id отдельно для каждой площадки. Без ID — только по самой публикации. Отсутствие проверки не означает снятие объявления.
