# Доработка агентского контура

Статус: реализация первого этапа. Элементы географии Auto.ru проверены в браузере;
полный сценарий сохранения проверен на локальной странице. Avito требует приёмки:
browser-control отклонил доступ к сайту по своей политике безопасности.

## Реализовано

- Сверка перед поиском может обновить только локальную ссылку Monitoring по
  единственному точному VIN из активной карточки свежего каталога дилера.
  Отсутствие VIN, неоднозначность, чужая привязка или блокировка запрещают замену.
  Ссылка и доказательство сохраняются в истории; импорт не отменяет замену.
- Проверка географии требует и правильный URL, и видимое подтверждение Москвы
  с нулевым радиусом. Auto.ru: панель `header-geo-content`, город `213`, значение
  ползунка, кнопки «0» и «Сохранить», повторное чтение и снимок доказательства.
  Универсальный fallback использует подписанный slider и кнопку применения.
  Неизвестный интерфейс даёт
  `geography_unverified`. Это не доказательство отсутствия машины.
- Полный Windows-запуск принимает `-Pace normal|cautious`, по умолчанию `normal`.
  Повторные осмотры кандидатов внутри сверки кешируются только на текущий цикл.
  Ускорение на живой площадке ещё не измерено.
- Очередь SQLite сохраняет задания, дедуплицирует их по commit, допускает одну
  выполняемую задачу и восстанавливает истёкшие lease. После трёх неудач — `failed`.
- Worker проверяет новые чистые commit. Задание maintenance запускает Hermes
  в отдельном git-worktree, сохраняет его ответ и выполняет Ruff/pytest над этим
  worktree с отдельным PYTHONPATH. Рабочая ветка автоматически не меняется.

## Команды из корня проекта

```powershell
.\.venv312\Scripts\python.exe scripts/agent_worker.py status
.\.venv312\Scripts\python.exe scripts/agent_worker.py once
.\.venv312\Scripts\python.exe scripts/agent_worker.py watch
```

`watch` — постоянно работающий процесс с проверкой очереди каждые 30 секунд.
Он не запускает мониторинг площадок и не загружает модель автоматически.
Для инженерного задания требуются установленный Hermes и доступная локальная
модель. Команда постановки: `python scripts/agent_worker.py enqueue-maintenance`.
Текст maintenance фиксирован в коде; произвольные shell-команды очередью не принимаются.
Артефакты — `artifacts/agent_kernel/`, рабочие деревья — `artifacts/agent_worktrees/`.

## Следующие обязательные этапы

1. Привязать browser-control к реальным элементам Auto.ru и Avito. Проверить
   сценарии Москва/200 км, другой город, отсутствие радиуса, CAPTCHA и смену DOM.
   Текущая универсальная реализация не считается приёмкой обоих сайтов.
2. Добавить сравнение фото и описаний малой VLM для кандидатов без VIN.
   Сохранять исходные изображения, отличие характеристик и альтернативных кандидатов.
   При нескольких похожих машинах оставлять `review_required`.
3. Добавить независимый аудит инженерного diff через Ouroboros или проверенный
   heavy fallback. Не принимать свободный текст «готово» за разрешение применения.
4. Перед автоматическим применением: разрешённые пути, неизменность существующих
   тестов и политик, точный базовый SHA, тесты в изолированном окружении, отсутствие
   активного мониторинга, пробный запуск, резервный commit и проверяемый откат.
   Сам worktree не является границей безопасности для исполняемого кода.
5. После этих проверок подключить единый диспетчер scan/LLM/maintenance и автозапуск
   Windows. Обрабатывать закрытие сессии, сон, перезапуск, таймауты дочерних процессов
   и освобождение моделей. Не запускать одновременно браузерный scan и инженерную модель.

## Постоянная работа

24/7 означает работающий supervisor и очередь, а не непрерывные запросы площадкам
или бесконечное изменение кода. Новые задачи формируются из подтверждённых дефектов,
новой версии и результатов контроля. Без новой информации повторный анализ
не нужен. CAPTCHA остаётся ручной; таблица маркетинга никогда не изменяется.

Пока этапы 3–5 не завершены, автоматическое изменение рабочей версии и постоянный
инженерный процесс не включаются. Это техническая незавершённость контура, а не
запрос повторного разрешения владельца на согласованную автономность.
