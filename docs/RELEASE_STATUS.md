### Мониторинг

- Auto.ru parser адаптирован к текущим легковым и LCV путям.
- Owner no-VPN probe выявил актуальные индивидуальные URL новых автомобилей
  `/cars/new/group/.../<listing-id>-<slug>/`. Селектор добавлен, а сводные
  model-group карточки исключены из позиций. ID теперь берётся из начала
  последнего сегмента, а не из случайного цифрового хвоста slug.
- Avito parser адаптирован к текущим `data-marker=item` и
  `item_list_with_filters/item(...)` карточкам и проверен живой выдачей.
- Страницы 1–3, canonical marketplace ID, позиция на странице, абсолютная позиция
  и повторные эпизоды реализованы.
- CAPTCHA/429/неизвестная разметка/неполный проход дают technical, не absence.
- Первый валидный miss — uncertain; второй открывает confirmed episode.
- Scan и dealer discovery защищены от параллельного запуска.
- Scan отказывается работать при `local_vpn|unknown` до создания audit-записей.
- Серии непоказов разделены по сетевому профилю; `local_browser` является
  выбранным рабочим контуром и открывает/закрывает `AbsenceEpisode`.
- Скриншоты хранятся в общей bind-mounted директории: локальный worker пишет,
  web-контейнер читает, retention сохраняется.

## История сетевой диагностики

Docker/headless и Selenium-инкогнито получали Avito HTTP 429. Обычная локальная
Chrome-сессия с сохраняемым профилем получила HTTP 200 и полную выдачу. Поэтому
старые 429 остаются в audit как технические результаты и не считаются непоказом.

После успешного V-Class probe немедленный повторный полный Auto.ru-run вызвал
SmartCaptcha. Run `c60f11a1-9d1c-4d79-b778-9e30740da696` корректно сохранён как
`partial`, а V-Class — как technical error, не как непоказ. После этого добавлены
точный marker этой CAPTCHA, пауза 2,5 с между страницами и остановка оставшихся
фильтров площадки до ручного подтверждения.

До добавления серверного gate один автозапуск старой stage-сборки успел создать
диагностические записи `local_vpn`: Auto.ru завершился частично, Avito получил
429. Эти append-only записи сохранены для аудита, явно помечены профилем и теперь
исключены из управленческой статистики. Они не считаются живой приёмкой.

Auto.ru ранее прошёл 9/9 фильтров и 27 страниц через no-VPN диагностику. Эти
наблюдения сохранены; следующий общий `local_browser`-run должен подтвердить обе
площадки в одном рабочем контуре.

Ручной запуск 07.09.2026 в 16:23 не обращался к площадкам: Chrome отвечал на
порту 19222, но не содержал управляемой вкладки, а Playwright попытался создать
неподдерживаемый контекст. Оба источника завершились за несколько секунд: 0
прочитанных страниц и 15 технических ошибок. В v0.6 worker создаёт вкладку через
локальный Chrome DevTools endpoint; подключение к тому же Chrome проверено без
сетевого перехода.

В v0.6 добавлены события прогресса после каждого фильтра и страницы, live-панель
dashboard, отдельные номера страниц на кнопках площадок и снимки точных карточек
целевых объявлений. Auto.ru ограничен контейнерами основной выдачи, пагинация
заменяет `page`/`p`, а не дублирует их. Код прошёл изолированные проверки; живой
no-VPN прогон новой версии остаётся приёмочным gate владельца.
