# Определения метрик

## Четыре разных объекта

- Автомобиль — запись с VIN/внутренней идентичностью.
- Размещение — текущая валидная ссылка этого автомобиля на Auto.ru либо Avito.
- Проверка площадки — ScanRun; полный общий запуск обычно создаёт два ScanRun.
- Наблюдение — автомобиль × фильтр × проверка; один автомобиль создаёт много наблюдений.

## Текущая картина

Размещения используют текущий ID и активные фильтры. Для каждого фильтра берётся
последнее наблюдение в выбранном периоде. При нескольких фильтрах общий статус
«Найдено» означает хотя бы один положительный результат; остальные доступны
в деталях. Отображаемая страница — минимальная среди последних положительных
результатов этих фильтров. Это не средняя позиция и не обещание видимости сейчас.
После смены ID или известной версии фильтра прежние результаты не применяются.
Исторические данные без версии фильтра трактуются в пределах доступной информации.
Если более позднее старое наблюдение не содержит ID ссылки, оно блокирует вывод
прежнего «найдено» как последнего состояния, но само не объявляется непоказом
текущей ссылки. Для неё отображается «Ещё не проверено» до нового измерения.
При известном обновлении фильтра более ранние наблюдения без версии исключены
из текущего состояния, но сохранены в истории периода.

## Статистика периода

Доля обнаружений = FOUND / (FOUND + ABSENT_CONFIRMED + ABSENT_UNCERTAIN).
TECHNICAL_ERROR и FILTER_MISMATCH исключены из знаменателя. При нулевом знаменателе
показывается «нет данных», а не 0%. Страницы 1/2/3 — частоты обнаружений на них.
Повторные успешные проверки учитываются повторно. Статистика периода включает
исторические ID; текущие размещения показывают статистику своей актуальной ссылки.

Все доверенные источники ограничены BUSINESS_TRUSTED_NETWORK_PROFILES. Новый
marketplace cycle создаёт только Mac host runner с VPN admission и inherited
host-lock FD; `cloud_no_vpn`, `local_no_vpn`, `local_vpn` и `unknown` не могут
создать новые наблюдения. Их исторические диагностические записи могут быть
видны в журнале, но не участвуют в метрике.
Выходные рассчитываются по Europe/Moscow. День без наблюдений явно обозначен.
Статистика не доказывает непрерывного отсутствия объявления между проверками.

## Цена и активность

Цена автомобиля берётся из исходного реестра, цена наблюдения — из карточки
площадки. История изменений реестра начинается с 0.7.0. Повторный одинаковый импорт
не создаёт новый event изменения. Импорт как операция всё равно записывается.
Изменения ссылки в реестре — прокси смены публикации, не подтверждение её даты.
Просмотры, клики, лиды и стоимость продвижения без источника этих данных отсутствуют.
