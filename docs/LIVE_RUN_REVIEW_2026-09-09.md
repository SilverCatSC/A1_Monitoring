## Подтверждённые дефекты

1. Баннеры снятия/продажи находились вне заголовка и известных классов статуса.
   Auto.ru 1130128385 явно показывает «Этот автомобиль уже продан»;
   Avito 8143909622 — «Объявление снято с публикации». Оба получили unknown.
   Это доказывает неактивность этих публикаций на момент снимка, но не продажу
   соответствующей машины компании и не ID её новой публикации.
2. В Avito Maextro счётчик заголовка показывает одну машину в Москве; второе
   извлечение относится к секции «1 объявление есть в другом городе»
   (Красногорск). Парсер учитывал обе карточки. На запросах страниц 1/2/3
   повторялась короткая выдача. Контроль дублей применялся только к продавцу.
3. У Zeekr Auto.ru страница 2 имеет HTTP 200 и счётчик 212 предложений, но
   снимок показывает начало секции «Похожие предложения» без основного списка.
   Причина пропажи списка — формат выдачи, пагинация или загрузка — пока не
   установлена. Называть её CAPTCHA или подтверждённым непоказом нельзя.
4. Для части FOUND Auto.ru отсутствует карточечный PNG. Исключение первого
   подходящего элемента прекращало попытку получить снимок; причина терялась.
5. Статус отдельного фильтра выводился как ok даже при пропущенных ссылках.
   pages_scanned в API сохранял максимум номера страницы, а не сумму просмотров.
