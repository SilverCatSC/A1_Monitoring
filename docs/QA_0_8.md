# Проверка обновления 0.8.0

Дата: 9 сентября 2026 года. Проверялись текущий Mac, локальное приложение,
PostgreSQL в Docker и изолированный Chrome для интерфейса.

## Подтверждено

- Локальный пакет и работающий контейнер: 0.8.0; Alembic 20260909_0006 (head).
- 144 изолированных теста прошли; Ruff src/tests/scripts без ошибок.
- git diff --check и компиляция src/scripts без ошибок.
- scripts/smoke_stage.sh: LOCAL_READY, 9 разделов и статические ресурсы HTTP 200.
- scripts/check_ui.py: 9 разделов на 1440 и 390 px, детализация автомобиля,
  переход из обзора с сохранением фильтров, три состояния прогресса.
- Заполненная форма сверки проверена отдельно: обязательные поля, отсутствие
  переполнения, отображение отказа для устаревшего результата, повторная
  доступность кнопки. Ответ API подставлялся только внутри тестового браузера.
- Для UI-проверок не создавались автомобили/наблюдения в рабочей БД, все внешние
  запросы браузера блокировались. Скриншоты: artifacts/ui_0_8/.
- На рабочем PostgreSQL отдельным тестом подтверждены сохранение блокировок
  scan/discovery/cycle при ORM commit и освобождение после завершения. Тест
  не менял бизнес-данные и не обращался к площадкам.

Покрытые тестами случаи: перевыкладка, запрет автоматического сопоставления по
модели, старый кеш, неполный каталог, остановка на CAPTCHA/429, ограничение
числа открытий старых ссылок, дубли ID, отдельный статус снятия, смешанный фильтр
с подтверждённой и устаревшей ссылками, подтверждение человеком, запрет чужого
кандидата, конфликт таблицы с закреплённой ссылкой, VLE new/group и Москва/0 км.

## Что остаётся проверить владельцу

Это проверка реализации, не живая приёмка Auto.ru/Avito. Требуется один запуск
без VPN с наблюдением окна Chrome: сверить принадлежность извлечённых карточек
каталогам A1, распознавание снятия, новый фильтр VLE, Москва/0 км и номера страниц.
CAPTCHA и фактический сетевой маршрут этими тестами не исключены.

Исторические результаты не пересчитаны: они остаются фактами прежней методики.
Сохранены ранее существовавшие изменения рабочего дерева. Commit/push и
редактирование внешних кабинетов не выполнялись.
