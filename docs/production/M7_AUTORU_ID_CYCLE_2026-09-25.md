## Task / граница

После разрешения владельца выполнен **один** живой MacBook-цикл только для
Auto.ru. Предыдущий отказ разрешённого браузера для Avito не обходился:
`--engines auto_ru` исключил посещение страниц Avito из каталога, поиска,
прямых карточек и ID-проверки. Чтение Avito-вкладок исходного фида не является
живой проверкой Avito. Это не полный двухплощадочный цикл и не M7 acceptance.

Команда: `run_monitoring_host_macos.sh --engines auto_ru --pages 1
--placement-identity`. Повторный запуск и автоматическая замена ссылок не
выполнялись.

## Analyse — расхождения ID и ссылок

Две сильные гипотезы перевыкладки: новая активная карточка содержит **точно тот
же placement ID**, что одна строка фида; старая ссылка из реестра открылась с
текстом «Этот автомобиль уже продан». Это **не** означает продажу автомобиля.
Обе гипотезы поставлены в очередь ручного подтверждения, URL в реестре не
менялся.

Владелец позже подтвердил, что обе машины действительно перевыложены и
сохранились в каталоге дилера. Старые ссылки в маркетинговой таблице при этом
не обновлены. Подтверждение владельца не означает, что URL уже изменены в БД:
это остаётся отдельным аудируемым действием оператора.

исправлен в коде и покрыт тестами для будущих циклов. После исправления прошли

приложение пересобрано и прошло `/health` и `/ready` на той же ревизии БД
`20260914_0011`. Повторного marketplace-цикла для этого не запускали.

## Write down — решение и пределы

Кандидаты на перевыкладку требуют ручного сравнения автомобиля и ID в блоке
описания перед подтверждением URL. Никаких правок исходной таблицы, ссылок БД
или объявлений не было. Остальные 21 `not_verified` нельзя превращать в
`missing`, пока покрытие ID неполно. Avito не проверялся.
