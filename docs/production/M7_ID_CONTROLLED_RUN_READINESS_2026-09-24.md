# Готовность контрольного ID-цикла — 24.09.2026

Статус: **живой цикл не начат**. Эта запись не заменяет M7 acceptance.

## Подтверждено

- В коде есть ограниченный этап чтения трёх фидов и открытия новых карточек
  продавца; он выключен по умолчанию и не меняет URL автоматически.
- Прямое read-only чтение CSV-export подтвердило структуру текущих вкладок:
  `autoru-feed-all` — 38 строк с ID, `avito-feed-new` — 23,
  `avito-feed-used` — 9. В Avito new сохранилась связь латинского
  `MBVC011220262508260009` с `AvitoId=8176281881`. Это сведения фида,
  не проверка текущего состояния объявления.
- MacBook host preflight завершился `HOST_RUNNER_PREFLIGHT_OK no_cycle_created=true`.
- Локальное приложение пересобрано после добавления экрана ID-сверки;
  `doctor.py --http --wait` вернул `LOCAL_READY`. Новый защищённый экран
  `/api/v1/dashboard/placement-identity` ответил HTTP 200 и честно сообщил,
  что живого ID-отчёта ещё нет. Это deploy интерфейса, не marketplace-run.
- Офлайн-тесты проверяют новую карточку с изменившимся AvitoId, узкую
  нормализацию кириллической буквы, неполный обход и доступ к отчёту/evidence.

## Стоп-факторы

1. Локальная проверка owner VPN admission вернула `expired`. Новый approval
   автоматически не создавался и настройки VPSUS не менялись. Формат и порядок
   подтверждения описаны в [VPN admission contract](VPN_ADMISSION_CONTRACT_2026-09-14.md).
2. Предыдущая попытка открыть Avito через разрешённый браузер получила отказ
   политики безопасности. Ни другой браузер, ни скриптовый обход для живой
   проверки не использовались.
3. В M7 нет утверждённой владельцем контрольной выборки с ожидаемыми страницей,
   ценой, годом, НДС и состоянием карточки для обеих площадок.

Следовательно, `PLACEMENT_RECONCILIATION_ENABLED` остаётся `false`, а новая
логика не объявляется принятой на живых объявлениях. Следующее действие —
owner-approved свежий VPN admission и разрешённый штатный доступ к площадкам,
после чего один контролируемый MacBook cycle с одноразовым
`--placement-identity` и ручная сверка выборки. Его
результат должен быть отдельно записан как `completed`, `partial` или `failed`.
