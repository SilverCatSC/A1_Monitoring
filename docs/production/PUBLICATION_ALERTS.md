# Сигналы о публикациях

С каждого нового прогона мониторинг сохраняет `publication_alerts` в отчёт
`placement_reconciliation.json`, краткий счётчик в итог цикла и сообщения
`СИГНАЛ` в журнал. Dashboard показывает раздел «Сигналы об изменении публикаций».
Сигналы текущего запуска также сохраняются отдельно от последних 80 событий
в `scan_progress.json`. Отправка во внешние чаты этим изменением не включается.

Сравнение берёт последний доступный валидный отчёт более раннего цикла отдельно
для каждой проверяемой площадки. В отчёте указан ID цикла сравнения. Повреждённые
и будущие отчёты пропускаются; отсутствие базы сравнения не означает ноль объявлений.

- Сокращение каталога — предупреждение уже на этапе каталога, даже если дальше
  не удалось прочитать фид. Сравнивается один адрес продавца. Легковые машины
  и коммерческий транспорт в итоговом сравнении учитываются отдельно.
- Исчезновение — ранее активная публикация явно снята либо не обнаружена
  в полностью прочитанном каталоге продавца. Продажа машины не предполагается.
- При неполном каталоге — «ранее активная публикация не подтверждена»,
  а сокращение числа наблюдаемых карточек остаётся предупреждением.
- Перевыкладка — новая активная ссылка с тем же точным `unique_id`.
  При неполном каталоге и неизвестном состоянии старой ссылки это кандидат,
  а не окончательно подтверждённая замена.
- Несколько активных ссылок с одним ID — дубль, одна ссылка автоматически не выбирается.
- Повторное появление ранее снятой ссылки — восстановление публикации.

VIN, цена, модель и визуально похожие кириллические символы не подтверждают
автоматическую перевыкладку. Для новой ссылки требуется точный ID из карточки.
Сигнал не изменяет исходную таблицу маркетинга. Существующий механизм
подтверждения/синхронизации ссылок сохраняет свои отдельные правила.

Причина сокращения обозначается как неизвестная: возможны перевыкладка,
снятие маркетингом, ошибка импорта или проблема площадки. Первое предупреждение
не ждёт установления причины. Сведения имеют даты соответствующих циклов;
сравнение само по себе не обновляет старые карточки и не запускает новый обход.

Открытые сигналы переносятся между циклами: одинаковый уменьшенный каталог
не означает восстановление. Сохраняются первая проверка обнаружения и исходная
база количества публикаций. При отсутствии свежей прямой проверки старое снятие
становится текущим предупреждением о неподтверждённом восстановлении, а не новой
заявкой о достоверно прочитанном снятии. Возврат прежней ссылки снимает открытый
сигнал; новая ссылка с точным unique_id формирует перевыкладку/кандидат.

Точечное уточнение может сохранять сигналы в `post_run_business_review` исходного
цикла. Оно привязано к SHA256 исходного отчёта и проходит проверку структуры,
источников и ссылок. Уточнение не меняет исходные карточки, индексы доказательств,
другие площадки или статус цикла. Следующий прогон использует и эти открытые сигналы.
