## Recovery boundaries

The tag preserves application source, tests and documentation. It does not
back up `.env`, the database, original source workbooks, browser profiles,
operator decisions, photo indexes, report artifacts or evidence. Retain those
separately under the existing local backup procedure. Never delete runtime data
when returning to this source checkpoint.

Restore the tagged source in a separate checkout first. Existing recovery
checkpoints are tied to scraper/configuration hashes and a six-hour age limit;
do not edit manifests to make incompatible observations reusable.

This is a tested Mac workflow, not a guarantee against future marketplace
markup, access-control or API changes.
