# Цикл от активного каталога — 7 октября 2026

## Порядок работы

1. Обновить маркетинговый реестр и получить свежие каталоги дилера.
2. Сверить активные карточки с сохранёнными ID публикаций. Ссылка с тем же
   ID берётся из свежего каталога; сохранённый адрес остаётся в истории.
3. Открыть карточки свежего активного каталога для сверки unique_id/содержания.
   Для одного ID площадки допускается одно открытие за цикл; результат
   сохраняется только в памяти этого цикла.
4. Выполнить поиск по настроенным фильтрам до пяти страниц для подтверждённых
   публикаций. Несопоставленные автомобили остаются в очереди сверки.
5. Использовать уже полученные данные карточек для отчёта; открыть только те
   подтверждённые активные карточки, которые ещё не посещались в этом цикле.
6. Сформировать результат поиска, расхождения и список непроверенных пунктов.

## Что сокращено

Обычный полный цикл не открывает старые адреса, отсутствующие в свежем
активном каталоге. В том числе после поиска он не обходит весь маркетинговый
реестр заново. Для отсутствующих публикаций сохраняются сведения: полный ли
каталог, исходная ссылка, возможные активные кандидаты и необходимость сверки.
Отсутствие в неполном каталоге не превращается в подтверждённое снятие или продажу.

Все результаты текущего открытия карточки используются повторно между
сверкой ID и финальной проверкой карточек, включая неизвестное состояние,
ошибку HTTP и закрытую карточку. Повторное использование ошибки не считается
успешной проверкой. Если карточка успела закрыться после загрузки каталога,
явная отметка снятия исключает её из поисковых целей до начала поиска.
Другой цикл не использует этот кэш.

Переходы между страницами каталога Auto.ru/Avito выполняются по обнаруженным
ссылкам навигации, с проверкой того же продавца. При отсутствии ссылки и
доказательства конца каталог остаётся неполным; выдуманный адрес следующей
страницы не запрашивается. Положительно найденные карточки сохраняются.
Обычный поиск сохраняет прежнюю пагинацию и предел пяти страниц.

## Границы

Сохраняются задержки между запросами и ручное ожидание CAPTCHA. Поэтому
фиксированная длительность не гарантируется. Ускорение достигается удалением
лишних посещений, а не учащением запросов.

Точное сопоставление unique_id, очередь неоднозначных связей и режим
`local_no_vpn`, подавляющий автоматическое обновление канонических ссылок,
сохраняются. Это изменение не создаёт отсутствующие поисковые фильтры и не
реализует полный смысловой аудит описаний. Активные карточки без привязки к
автомобилю остаются в результатах сверки ID; их позиции нельзя приписывать
конкретному автомобилю по одному совпадению модели.

## Локальная проверка

Регрессионные тесты проверяют:

- ноль открытий старых ссылок при полном и неполном каталоге;
- открытие свежего адреса при том же ID без изменения реестра;
- повторное использование ID-проверки карточки без нового открытия;
- сохранение HTTP-ошибки при повторном использовании результата;
- ограничение числа открытий активных карточек;
- переход по фактической ссылке каталога и отказ от перехода к другому продавцу;
- сохранение найденных карточек при неподтверждённом конце каталога;
- прежний поиск до пятой страницы на обеих площадках.

Живой прогон после изменения требуется отдельно для измерения времени и
проверки актуальной разметки сайтов.
