# A1 Monitoring — handover, 2 November 2026

Release tag: `stable-2026-11-02`. This release extends `stable-2026-10-30` with
public report publication and targeted Auto.ru Range Rover recovery.

## Operating scope

Ready for regular, operator-assisted use on the existing configured Mac through
**A1 Monitoring.app**. The Mac must be awake, unlocked and connected. A person
solves CAPTCHA and uses Continue after an interrupted run. The program builds
the report and marketing summary without this chat. It does not correct adverts
or send marketing messages automatically, and it does not change VPN settings.

1. Open the Desktop app and choose **Start monitoring** once.
2. Complete access checks in the monitoring Chrome window when notified.
3. Use **Continue unfinished checks** if the run stops with unfinished work.
4. Open the latest report in the app. Check its date and coverage warnings.
5. Share the permanent public report after checking its scan date:
   https://silvercatsc.github.io/A1_Monitoring/

The public report updates after a report-bearing run or successful recovery.
Publication failures preserve the local result and the previous dated public
snapshot. Continue retries publication when no technical checks remain.
See [publication details](../operations/SHARED_REPORT.md).

## Open findings and limits

- Six Auto.ru adverts have no published `unique_id`. Their identity is unresolved;
  this does not mean they were unread or inactive. The report deliberately retains
  the warning and can remain partial despite completed technical checks.
- Marketplace CAPTCHA, rate limits, outages and HTML changes cannot be guaranteed
  away. The earlier grouped-dealer Range Rover layout was not parsed reliably.
  The targeted retry returned individual offers and completed successfully; this
  release adds its recovery path, not a universal parser for every future layout.
- Checkpoints require matching code/settings and valid age (up to six hours).
  Expired or incompatible work cannot be presented as freshly checked.
- Feed/schema/access errors and changed marketplace layouts can still require
  source-owner or developer attention. "Ready for regular use" is not a claim
  that every future external failure can be resolved with Continue.
- Public reports are read-only snapshots; their date matters. External photo
  availability can change independently. They are not a cloud scanning service.
- Windows, another Mac and a permanently unattended server are not accepted
  deployment targets for this handover.

## Source delivery and rollback

The tag contains source, tests and documentation. A source ZIP is not a standalone
installer and does not include the configured database, credentials, reports,
browser profile, local publication settings or operator decisions. Keep the
existing Mac installation and runtime data intact.

For rollback, first inspect the tagged source in a separate checkout. Do not
reset the working installation or overwrite its data. Follow the existing
[maintenance guide](../operations/MAINTENANCE.md) for environment and backups.

Only the generated report is published on `gh-pages`; application source is on
`codex/fix-avito`. No `.env`, database, raw evidence or browser profile is included
in the public report branch.
