## Analyse / Write down — выбранная граница данных

Каталог показывает ID отдельно для Auto.ru и Avito, только если последняя
сверка текущей ссылки получена через доверенный профиль и содержит:

1. корректный ASCII ID из описания активной прямой карточки; или
2. ровно один корректный ID в доказанном кандидате перевыкладки с точным
   совпадением фида и карточки, ссылкой и снимком.

При конфликте двух ID, неизвестном профиле или отсутствии доказательства
каталог пишет «Не подтверждён». Для кандидата видно предупреждение
«подтвердить ссылку». Эта UI-проекция не меняет `Listing`, источник маркетинга
или URL; Avito без живой проверки не получает выдуманный ID.
