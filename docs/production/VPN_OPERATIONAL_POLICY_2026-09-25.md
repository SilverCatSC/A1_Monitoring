# Повседневный VPN-допуск на MacBook — 25.09.2026

Для обычного запуска host-runner теперь использует локальную политику владельца
и текущий статус подключения VPSUS. Это **готовность к запуску**, не доказательство
маршрута трафика для каждого домена и не приёмка M7. Истёкшая 24-часовая
`attestation.json` больше не останавливает повседневный runner; она остаётся
отдельным историческим форматом подтверждения маршрутов для M7.

Локальный, исключённый из Git файл `artifacts/vpn_admission/policy.json` должен
находиться в каталоге с правами `0700` и иметь права `0600`, принадлежать
текущему пользователю macOS, не быть ссылкой и не иметь extended ACL. Его точная
схема (без дополнительных полей):

```json
{
  "schema_version": 2,
  "status": "approved",
  "services": {
    "chatgpt": {"route": "vpn_exit"},
    "auto_ru": {"route": "direct_physical_connection"},
    "avito": {"route": "direct_physical_connection"}
  }
}
```

Файл фиксирует согласованное направление, но **не измеряет** фактический IPv4/IPv6
egress. На этом MacBook он создан после решения владельца о ChatGPT через VPN и
Auto.ru/Avito напрямую. Не копировать его на другой компьютер как доказательство
приёмки. Проверка перед циклом:

```bash
.venv312/bin/python -m app.service.vpn_admission \
  --operational-policy artifacts/vpn_admission/policy.json
```

Успех означает только, что приватная политика совпадает с точной схемой, а
macOS `scutil --nc` сейчас сообщает `Connected` именно для VPSUS. Несовпадение,
отсутствие файла, небезопасные права, другой VPN, Windows/контейнер или
недоступность системного статуса дают отказ до Chrome и записи нового цикла.
`--preflight` проверяет готовность приложения без чтения политики и без
обращения к площадкам.

Для принятия split-tunnel нужны отдельные наблюдения фактического маршрута обоих
IP-семейств и решение владельца по [M7](ACCEPTANCE_M7.md). Проверка статуса VPN
этого не заменяет. При изменении правил VPSUS пересмотреть policy и M7 evidence.
Более того, доступ к Avito через разрешённый браузер ранее был отклонён
ограничением безопасности среды. Не запускать обходной браузер или скрипт ради
живой проверки; этот stop-rule независим от успешного VPN-допуска.
