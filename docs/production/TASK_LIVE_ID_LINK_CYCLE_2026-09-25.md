`autoru-feed-all`, `avito-feed-new`, `avito-feed-used` и
`Размещение_автомобилей`. Читались только ограниченные диапазоны ID/action/VIN/
URL и статуса. Это срез таблицы 25.09, а не наблюдение площадок.

| Источник | Срез | Ограничение связи по VIN с основным реестром |
| --- | --- | --- |
| Auto.ru | 38 ID: 32 `show`, 6 `hide`; дублей ID нет | 3 без VIN в фиде, 1 VIN отсутствует в реестре, 6 строк фида соответствуют повторяющемуся VIN в двух строках реестра |
| Avito new | 23 ID; дублей ID нет | 3 без VIN, 4 строки фида соответствуют повторяющемуся VIN |
| Avito used | 9 ID; дублей ID нет | 1 VIN не найден в реестре |

При **однозначном** совпадении VIN между фидом и основным реестром:

- Auto.ru `show`-строки фида **30 и 31** соответствуют актуальным строкам
  реестра **29 и 30**; прямых Auto.ru URL в этих строках нет.
- Avito new строки фида **23 и 24** соответствуют тем же актуальным строкам
  реестра **29 и 30**; прямых Avito URL также нет.
- Auto.ru `show`-строка фида **42** соответствует строке реестра **44** без
  Auto.ru URL, но основной реестр помечает её `Не актуально`. Это конфликт
  статусов источников, а не подтверждённое действующее объявление.
- Для 20 сопоставимых пар Avito с однозначным VIN, заполненным `AvitoId` и
  числовым ID в URL основного реестра значения совпали (12 new, 8 used).
  Это не доказывает, что ссылки ещё активны: фид и реестр могут запаздывать.

Повторяющийся VIN, отсутствующий VIN или пустая ссылка не дают права назначить
новый URL по сходству модели, цене либо картинке. В частности, новый AvitoId
после перевыкладки может ещё не попасть в фид.
