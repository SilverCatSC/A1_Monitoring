# Task — подтверждение перевыкладки по точному ID, 25.09.2026

## Task

Довести до рабочего сценария две подтверждённые владельцем перевыкладки Auto.ru:
`MBVC011220252508260001` и `MBVC011220252508260007`.
Оператор должен сравнить старую и новую ссылки, увидеть основание ID-сверки и
снимок новой карточки, затем подтвердить новую ссылку. Старый URL остаётся в
журнале. Таблица маркетинга не редактируется автоматически.

## Test / Analyse — исходное состояние

- В контролируемом цикле `86c5ad62-d47c-4188-a227-02ddbee9786c` обе старые
  ссылки дали статус закрытой карточки; в каталоге дилера открыты активные
  карточки с тем же точным ID.
- Очередь прежней сверки содержит много кандидатов только по семейству модели;
  без отдельного пути оператору легко выбрать похожий автомобиль.
- Маршрут ручного подтверждения уже сохраняет `ListingLinkEvent`, защищает
  локальную ссылку от перезаписи импортом и закрывает историю старого Offer.
  Он требует роль оператора/администратора, свежую сверку и не занятую другим
  автомобилем новую ссылку.

## Write down — правило безопасного действия

При одном точном ID-кандидате показывается отдельный блок в карточке машины:
старая ссылка, новая ссылка, ID, строка фида и снимок. Подтверждение возможно
только если отчёт цикла связывает этот ID с этой сверкой и URL, карточка была
активной, а снимок и manifest проходят проверку целостности. Два точных
кандидата, неподходящий профиль сети, повреждённое доказательство или сверка
старше 24 часов блокируют действие. Кандидаты только по модели остаются
недоступными в этом сценарии.

После подтверждения новая ссылка становится текущей в Monitoring, а старая
видна в журнале `Было → стало`. Сама отметка площадки «продано» по старой
ссылке не считается фактом продажи автомобиля.

## Task / Run — проверка

- Проверки покрывают видимость двух ссылок и ID, доказательство, отказ при
  повреждённом снимке/старой сверке/нескольких точных кандидатах/выборе
  похожей модели, а также сохранение старой ссылки после подтверждения.
- Автоматические тесты используют изолированную БД и тестовый снимок;
  живые URL они не меняют.
- Локальная проверка интерфейса после развёртывания фиксируется отдельно.

## Открытая граница

Владелец подтвердил факт двух перевыкладок, но действие по обновлению
текущих ссылок в рабочем Monitoring остаётся за человеком в интерфейсе.
Пока кнопка не нажата, отображаются обе ссылки, но текущей остаётся старая.
Если пройдёт 24 часа с момента проверки, нужен новый контролируемый цикл.
