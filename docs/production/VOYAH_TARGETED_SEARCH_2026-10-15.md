# Точечный поиск Voyah Dream

Фильтр `avito_voyah_dream_all`: общий поиск модели без разделения на новые и
подержанные, Москва, `radius=0`, `searchRadius=0`, `localPriority=0`.
Модельный маршрут Avito — `voyah/dreamer-ASgBAgICAkTgtg2o8OMC4rYNytbXEA`,
полная ссылка получена от владельца 2026-10-15. Короткий путь `voyah/dream`
не работает и больше не используется.
Глубина — до пяти страниц, с остановкой на подтверждённом конце выдачи.
Сброс модели или географии при перенаправлении останавливает обход сразу
после сохранения снимка первой страницы и даёт неполный результат, а не вывод «5+».

```bash
cd /Users/filaret/Desktop/Monitoring &&
./scripts/run_monitoring_host_macos.sh \
  --diagnostic-routing \
  --search-only avito_voyah_dream_all \
  --pages 5 \
  --captcha-wait-seconds -1 \
  --pace normal
```

Режим сохраняет прежние проверки GUI, блокировку host runner и выбранный
сетевой режим. VPN не отключается; исходящий маршрут не считается проверенным.
CAPTCHA ожидает ручного прохождения без тайм-аута.

Выполняется только один поиск. Каталог дилера, прямые карточки, импорт источника,
восстановление старых циклов и запись нового цикла в БД не запускаются.

В терминале выводится `HOST_RUNNER_SEARCH_RESULT` с точным путём к
`artifacts/host_runs/<run>/search_result.json`. В том же каталоге находятся
`host_runner.log`, `status.json` и `exit_code.txt`. JSON содержит все найденные
ссылки, страницы и позиции, диагностику, отдельный ID проверки и её время;
снимки поиска сохраняются в `artifacts/evidence`.

Успех: `HOST_RUNNER_SEARCH_OK no_cycle_created=true`. Неполный результат
не повторяется автоматически. Отсутствие нового MonitoringCycle ожидаемо.
После ручного запуска результат можно добавить к отчёту как отдельную проверку
с собственной датой, сохранив исходную выдачу старого цикла.
