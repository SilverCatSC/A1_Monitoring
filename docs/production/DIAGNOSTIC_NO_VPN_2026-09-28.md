# Разовый MacBook-тест без VPN

Владелец запросил отдельный Finder-ярлык на рабочем столе для полного
диагностического обхода Auto.ru и Avito при выключенном VPSUS. Это явное
исключение для сравнения доступности площадок, **не изменение** обычной
production-политики с включённым VPSUS.

## Запуск

1. Владелец сам отключает VPSUS до запуска. Ярлык не управляет VPN.
2. Дважды нажимает «Проверка Auto.ru и Avito без VPN.command» на рабочем столе.
3. MacBook host-runner требует разблокированную GUI-сессию, свой kernel-lock,
   готовые app/db и статус `Disconnected` для VPSUS без другого подключённого
   macOS VPN. Если условие не выполнено, цикл не создаётся.
4. Выполняется один осторожный цикл с обеими площадками, максимум 3 страницы
   каждого фильтра и ожиданием человека для интерактивной CAPTCHA до 180 секунд.
   HTTP 429, CAPTCHA и ошибки сети остаются технической неполнотой; нет серии
   повторов, обхода защиты или автоматического переключения IP.
5. После завершения ярлык открывает локальный HTML-отчёт именно нового цикла
   и папку его файлов. При отказе до создания цикла открывает только папку
   журнала; старый результат не выдаётся за новый.

Файлы хранятся локально в `artifacts/diagnostic_no_vpn/<время>/` и исключены
из Git: `host_runner.log`, `progress.json`, `cycle_status.json`,
`scan_status.json`, `result.html`. Дополнительные снимки и ID-сверка остаются
в `artifacts/evidence/cycles/<cycle_id>/`; история — в PostgreSQL.

## Границы данных

- Цикл получает сетевой профиль `local_no_vpn`, не является M7/production
  приёмкой и не входит в доверенные бизнес-метрики дашборда.
- Автоматическая замена ссылок по ID в этом режиме подавлена. Тем не менее
  импорт реестра и запись диагностических наблюдений происходят в ту же
  локальную БД; это **не** полностью изолированная копия данных.
- Проверка `scutil` показывает состояние macOS VPN-сервиса, но не доказывает
  физический маршрут IPv4/IPv6, отсутствие системного прокси или доступность
  площадок. Наличие объявления подтверждается только соответствующим
  валидным наблюдением и evidence.
- Прежний ярлык с включённым VPSUS и его VPN policy остались неизменными.
  Для новой production-схемы без VPN нужны отдельные решение и приёмка.
