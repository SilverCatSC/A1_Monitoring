# Приватная браузерная сессия на цикл: эксперимент

Статус на 2026-09-28: код реализован, локальные тесты пройдены; снижение
CAPTCHA/HTTP 429 на живых площадках **не подтверждено**. Это не production
acceptance и не способ обхода защиты площадок.

## Task

Сохранить независимость от личной истории и cookies оператора, но не терять
состояние браузерной проверки между карточками одной площадки. Предыдущая
реализация создавала новый приватный контекст на каждое посещение. Если
Auto.ru принимал ручное прохождение интерактивной CAPTCHA, следующий URL
получал новый контекст и не мог воспользоваться результатом этой проверки.

## Test

Один разрешённый цикл получает один временный приватный контекст для Auto.ru
и отдельный — для Avito. Внутри контекста каждая проверка открывает и закрывает
свою страницу; cookies и другое состояние могут сохраняться только до конца
этого цикла. Контексты закрываются при успешном завершении и при ошибке.
Отдельный цикл получает новые контексты; storage state не сохраняется на диск.
Все этапы — кабинет дилера, сверка ID и ссылок, выдача поиска, прямая карточка
— используют один event loop и соответствующий контекст площадки.

Локальная проверка: `python -m pytest -q` — 447 passed; `ruff check src tests
scripts tools` — без ошибок. Unit-тест подтверждает повторное использование
контекста внутри цикла, разделение площадок и закрытие по окончании. Живой
запуск с площадками ещё не выполнялся после изменения.

## Analyse

Плюс подхода: каждый цикл стартует без личной истории и авторизации, а
проверки внутри цикла сохраняют необходимое состояние одной площадки. Минус:
cookies внутри цикла могут влиять на выдачу; объективность оценивается не
самим словом «инкогнито», а фиксированными фильтрами, регионом, порядком
проверок и сохранёнными наблюдениями. Раздельные контексты исключают обмен
состоянием между Auto.ru и Avito.

Результат для Auto.ru CAPTCHA неизвестен до живого теста. Avito в прежнем
цикле вернул HTTP 429 на **первом** запросе каталога; повторное использование
контекста не может устранить отказ, который происходит до второго запроса.
HTTP 429 остаётся технически непроверенным состоянием, а не отсутствием
объявлений. Не запускать серию быстрых повторов для проверки гипотезы.

## Write down → следующий Task/Run

После допустимого сетевого preflight выполнить **один** контролируемый полный
цикл через `./scripts/run_monitoring_host_macos.sh --engines auto_ru,avito
--pages 3`. Сопоставить журнал challenge/429, пройденные фильтры и карточки,
статус полноты и evidence с предыдущим циклом. Успех эксперимента — обе
площадки дают проверяемые данные без загрязнения личным профилем; отсутствие
CAPTCHA само по себе не является гарантируемым критерием.

Если Auto.ru покажет интерактивную CAPTCHA, сохранить уже реализованное
ожидание человека **в той же странице**, затем продолжить цикл. Если Avito
снова вернёт HTTP 429 или неинтерактивный запрет, зафиксировать блокировку и
не считать площадку проверенной. Отдельно спроектировать безопасное
продолжение незавершённых проверок после восстановления разрешённого доступа;
не маскировать его автоматическим повтором в плотном цикле.
