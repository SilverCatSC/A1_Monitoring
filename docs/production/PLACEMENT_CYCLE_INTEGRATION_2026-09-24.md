# Сверка ID в полном цикле — этап интеграции, 24.09.2026

Статус: подключено к MacBook-циклу в коде, **выключено по умолчанию** до
контролируемой живой приёмки. Офлайн-тесты и чтение фидов не подтверждают
доступность текущих карточек Auto.ru/Avito.

## Что делает этап

При `PLACEMENT_RECONCILIATION_ENABLED=true` после обычного поиска и проверки
старых ссылок цикл:

1. читает три вкладки фида (`autoru-feed-all`, `avito-feed-new`,
   `avito-feed-used`) из workbook, заданного `PLACEMENT_FEED_WORKBOOK_URL` или
   `HEAD_TABLE_GOOGLE_SHEET_EXPORT_URL`; основной импортный workbook может
   быть **другим**, поэтому URL `SOURCE_GOOGLE_SHEET_EXPORT_URL` для фидов не
   используется;
2. берёт только карточки, найденные каталогом продавца в **этом** цикле, и
   повторно использует уже сохранённые проверки старых ссылок;
3. открывает остальные карточки в пределах `SELLER_IDENTITY_CHECKS_LIMIT`
   (по умолчанию 40), с pacing, видимым Chrome и прямым evidence;
4. сравнивает ID в описании с фидом, учитывая только известные кириллические
   двойники в первых четырёх символах. `AvitoId` — дополнительное подтверждение
   или review-кандидат, но не единственное доказательство при запаздывании фида;
5. сохраняет read-only отчёт `artifacts/cycles/<cycle_id>/placement_reconciliation.json`
   с хешами фидов, полнотой обхода, предупреждениями и кандидатами перевыкладки.
   Краткая сводка есть в `monitoring_cycles.summary` и `/status/cycles/{cycle_id}`.

Отчёт не меняет ссылки в реестре, маркетинговую таблицу, объявления или статус
продажи. Подтверждение новой ссылки остаётся действием оператора по evidence.

## Честные границы результата

- Недоступный фид даёт `unavailable`, неполный каталог, лимит или карточка без
  evidence — `partial`. Такой цикл не может получить `completed` только за счёт
  успешной поисковой выдачи.
- Старая ссылка с пометкой «продан» не означает продажу автомобиля: при новом
  URL и том же подтверждённом ID вывод — `republication_candidate`.
- Если ID отсутствует или не поддаётся узкой нормализации, совпадение одного
  `AvitoId` даёт `platform_id_candidate`, а не новую ссылку.
- При противоречии ID в описании и фида — `identity_conflict`; автоматическое
  разрешение по модели, цене, фото или году запрещено.
- Один ID может относиться к новой продаже только по отдельному решению
  владельца данных. Нельзя переносить историю физического автомобиля по
  одному placement ID.

## Что осталось до включения

Проверить актуальный MacBook/VPSUS gate, доступ к публичным карточкам и одну
контрольную выборку с полным evidence. Затем включить флаг только для одного
контролируемого цикла, сверить находки с человеком и лишь после этого решать
вопрос о регулярном режиме. Автоматическая замена ссылок не включается этим
этапом.
