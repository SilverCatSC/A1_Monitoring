# Перевыкладки и сверка продавца · 0.8

## Что выявлено в коде до изменения

1. local_scan.py обновлял таблицу и сразу вызывал MonitorService. Существующий
   DealerDiscoveryService в этом локальном пути не использовался.
2. Кандидаты продавца сохранялись отдельно, но не проверяли актуальность целевых URL.
3. Непустая ссылка входного источника могла перезаписать исправление менеджера.
4. scan_filter.complete означал прохождение заданных первых N страниц. Для
   полного каталога продавца этого недостаточно, хотя старый discovery трактовал
   такой результат как основание деактивировать неувиденные записи.
5. Auto.ru new/group URL конкретного объявления принимался валидатором за фильтр.
6. В VLE использовался прежний общий /mercedes/vle/new/ URL. Новый group URL и
   категория new распознаются; поколение/конфигурация сохраняются в фильтре.

## Новый полный цикл

Импорт опубликованного источника → сохранение подтверждённых локальных ссылок →
видимый Chrome → три каталога продавца → сверка ID → поисковые фильтры 1–3 → отчёт.

Источники заданы владельцем, без поиска других дилеров:

- https://auto.ru/diler/cars/all/a1_avto_moskva/
- https://auto.ru/diler/lcv/all/a1_avto_moskva/
- https://www.avito.ru/brands/a1auto/all/avtomobili?src=search_seller_info&iid=8047929828&sellerId=e4036231f69cc5cfc365db2f79600230

Сверяются только включённые --engines. На каталог выделено до 5 страниц
(SELLER_PREFLIGHT_PAGES, максимум 10); для старых отсутствующих ссылок — до 5
дополнительных открытий на площадку за цикл (SELLER_DIRECT_CHECKS_LIMIT).
Действуют прежние осторожные паузы. Первичные признаки снятия читаются только
из заголовка/статуса объявления, не из блока рекомендаций. Отсутствие такого
маркера не считается доказательством активности. 404 не доказывает продажу.

## Правила решений

| Ситуация | Действие |
| --- | --- |
| Тот же ID в свежем каталоге | Допустить к поисковому мониторингу |
| ID встретился в неполном каталоге | Положительное членство можно использовать, полнота не утверждается |
| ID отсутствует, найдена похожая модель | Предложить кандидатов, ждать подтверждения |
| Объявление отмечено снятым/проданным | Отдельная отметка; не считать это продажей машины компании |
| CAPTCHA / 401 / 403 / 429 / уход на login | Остановить обращения к этой площадке |
| Старый кеш / непонятная разметка / лимит страниц | Не подтверждать актуальность по отсутствующим данным |
| Одна ссылка у нескольких активных машин | Неоднозначная связь; не допускать автоматический непоказ |
| В таблице снова старая ссылка | Сохранить подтверждённую локальную связь, показать расхождение |

Непроверенная связь в поисковых наблюдениях записывается как technical_error с
seller_preflight_unresolved и ID сверки. Она не открывает/не увеличивает серию
непоказов. Сам каталог не создаёт FOUND и не подмешивает свои страницы в статистику.

## Подтверждение

Кандидаты подбираются по семейству модели; цена отображается как справочная.
Это не автоматический VIN-match. Проверка VIN/комплектации/фото остаётся у
человека — сохранён прежний принцип BIBLE. Выбор, автор и основание записываются.
Сверка старше суток или изменившаяся ссылка требуют обновления; чужой кандидат
либо ссылка другого активного автомобиля отвергается.

После подтверждения требуется следующий цикл для свежей сверки и измерения
позиции. Таблица Google Sheets не меняется. Новый ID не наследует старую позицию
и серию непоказов. Записи прежних наблюдений сохраняются.

## VLE

Владелец сообщил новую целевую публикацию:
https://auto.ru/cars/new/group/mercedes/vle/25032431/25069598/1133334954-b51707f0/

Фильтр: /moskva/cars/new/group/mercedes/vle/25032425-25032429/ с
catalog_filter=mark=MERCEDES,model=VLE,generation=25032425,configuration=25032429,tech_param=25032431.
К нему добавляются ранее утверждённые geo_radius=0 и rid=213; прочие параметры
не удаляются. ID фильтра сохраняется, версия увеличивается.

При чтении рабочей БД обнаружена одна активная запись VLE, VIN пуст.
Явная ссылка владельца позволяет подтвердить эту локальную связь, но не
устраняет риск идентичности без VIN: изменение модели/года/комплектации во
входной таблице может изменить её составной ключ. Нужен VIN или стабильный
внутренний идентификатор; связывать историю разных машин по похожести нельзя.

## Границы проверки

Обычное удалённое чтение указанных страниц не дало каталог: Auto.ru возвращал
страницу входа, Avito не был прочитан. Это не доказывает их недоступности в
локальном Chrome владельца. Фикстуры и UI-тесты не являются живой приёмкой.
Селекторы каталогов, их фактическая полнота и распознавание отметок снятия
проверяются на контрольном запуске без VPN. Отклонение формата должно давать
неопределённость, а не ложный непоказ. Нельзя гарантировать отсутствие CAPTCHA.
