# Критерии приёмки A1 Search Monitor v1

> Этот документ содержит историческую матрицу проверок. Его отметки `[x]` не
> означают закрытие текущего M7: для production используйте
> [M7 acceptance runbook](production/ACCEPTANCE_M7.md), где нужны свежие
> evidence, целевые устройства и owner decision.
> Current host contract additionally supersedes the old direct `/scan` model:
> only the Mac host runner with approved VPN operational policy, connected VPSUS and inherited host-lock FD can
> create a marketplace cycle; `cloud_no_vpn`, `local_no_vpn` and `local_vpn` cannot.

## 1. Локальный исполнитель

- [x] Реальный Avito-фильтр проходит через обычный локальный Chrome без headless.
- [x] Профиль Chrome сохраняется между запусками.
- [ ] После входа пользователя локальный график восстанавливается автоматически.
- [ ] Пропущенный из-за выключенного компьютера запуск виден как технический пробел.
- [x] Каждый живой прогон хранит проверенный `network_profile`; VPN-stage не смешивается с production.
- [ ] После перезапуска сервера расписание восстанавливается автоматически.
- [ ] Пропущенный запуск обнаруживается и отображается как технический инцидент.

## 2. Импорт и изменение структуры

- [ ] Перестановка всех столбцов не меняет результат импорта.
- [ ] Добавление неизвестного необязательного столбца не останавливает мониторинг.
- [x] Известный алиас заголовка сопоставляется корректно.
- [ ] Удаление обязательного поля помещает импорт в карантин.
- [ ] При карантине последняя корректная версия остаётся активной.
- [ ] Два VIN в одной ячейке не объединяются молча.
- [ ] Пустые и повторные VIN не разрушают идентичность автомобилей.
- [ ] В отчёте видно время и результат последнего импорта.

## 3. Проверка выдачи

- [x] Каждый активный фильтр проверяет страницы 1, 2 и 3.
- [x] Объявление на странице 1 получает правильную страницу и позицию.
- [ ] То же подтверждено для страниц 2 и 3.
- [x] Позиция внутри страницы и абсолютная наблюдаемая позиция сохраняются отдельно.
- [x] Один фильтр загружается один раз на страницу, а не отдельно для каждого автомобиля.
- [ ] Прямые ссылки используются для диагностики отсутствующих объявлений.
- [ ] Переопубликованное объявление не перезаписывает историю предыдущего `listing_id`.

## 4. Защита от ложных результатов

- [x] CAPTCHA создаёт `technical_error`, а не непоказ.
- [ ] Страница авторизации вместо выдачи создаёт `technical_error`.
- [ ] Ошибка разбора карточек не воспринимается как пустая выдача.
- [ ] Успех страниц 1–2 и ошибка страницы 3 не создают подтверждённый непоказ.
- [ ] В интерфейсе нет утверждения «страница 3+» без фактического наблюдения.
- [x] В каталоге на каждой площадке показана последняя фактически найденная страница.
- [x] Для нового найденного объявления превью использует снимок точной карточки,
  а не случайную видимую область страницы.
- [x] Терминал и dashboard показывают площадку, фильтр и страницу текущего прогона.
- [ ] Карточечные снимки и номера страниц подтверждены владельцем на живом прогоне.
- [ ] Бизнес-метрика видимости исключает технически неизвестные результаты из знаменателя либо явно показывает покрытие.
- [x] Прямой `/scan` при любом non-Mac/unadmitted profile, включая
  `cloud_no_vpn`, `local_no_vpn`, `local_vpn` и `unknown`, блокируется до создания
  наблюдений; одного boolean/file недостаточно без inherited host-lock FD.
- [x] Недоверенные VPN-наблюдения не входят в KPI, превью и статистику страниц.

## 5. Эпизоды непоказа

- [ ] Один подтверждённый непоказ не открывает тревогу.
- [x] Первый валидный непоказ создаёт `absent_uncertain`, второй подряд —
  `absent_confirmed` и эпизод с момента первого.
- [ ] Последующее обнаружение закрывает эпизод.
- [ ] История закрытого эпизода сохраняется.
- [ ] Техническая ошибка внутри интервала показывается как пробел наблюдения.
- [x] Локальный no-VPN miss не открывает и не закрывает production-эпизод.
- [ ] Рассчитывается общая длительность и часть, попавшая на выходные.

## 6. Выходные

- [ ] Расписание выполняется в субботу и воскресенье.
- [ ] Пилот охватывает минимум два полных уикенда.
- [ ] Понедельничный отчёт показывает непоказы и технические пробелы отдельно.
- [ ] Часовой пояс всех расчётов — Europe/Moscow.

## 7. Отчёт

- [x] Есть рабочая управленческая сводка, каталог, история, карточка автомобиля,
  очередь «Ошибки объявлений» и здоровье системы.
- [ ] На основных экранах видно время последнего достоверного наблюдения.
- [x] Можно перейти от агрегата к автомобилю, объявлению и доказательству.
- [x] Работают фильтры по площадке, марке, модели, статусу и периоду.
- [x] Интерфейс пригоден для настольного и мобильного экрана.

## 8. Обратная связь

- [x] Менеджер создаёт обращение из карточки объявления.
- [x] Обращение можно связать с конкретным наблюдением.
- [x] Сохраняются автор, время, категория и комментарий.
- [x] Работает жизненный цикл статусов обращения.
- [x] Все изменения статуса аудируются.
- [x] Обращение не изменяет реестр автоматически.
- [x] Закрытие требует результата проверки.

## 9. Безопасность

- [ ] В репозитории и истории версий нет секретов.
- [ ] Сервисный доступ к таблице ограничен чтением.
- [ ] Роли проверяются на сервере.
- [ ] Административные страницы недоступны анонимному пользователю.
- [ ] Логи и доказательства не содержат cookie и токены.
- [ ] Настроен срок хранения диагностических материалов.

## 10. Надёжность и восстановление

- [x] База резервируется автоматически каждый день.
- [x] Выполнено успешное восстановление в изолированную тестовую базу stage.
- [ ] Обновление адаптера можно откатить.
- [ ] Сбой одного адаптера не останавливает импорт и второй адаптер.
- [ ] Веб-отчёт остаётся доступен при остановленном worker и показывает устаревание данных.

## 11. Production Gate

Версия 1 может считаться рабочим продуктом, когда:

- [ ] все критические критерии выше пройдены;
- [ ] завершён 14-дневный параллельный пилот;
- [ ] владелец утвердил список фильтров и пользователей;
- [ ] документированы известные ограничения Auto.ru и Avito;
- [ ] согласован регламент реакции на технические и бизнес-инциденты;
- [ ] результаты пилота проверены вручную на контрольной выборке;
- [ ] нет дефектов, создающих ложный подтверждённый непоказ.
