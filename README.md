# A1 Search Monitor

Локальное приложение для контроля объявлений A1 на Auto.ru и Avito. Проверяет,
появляются ли машины на первых трёх страницах утверждённых фильтров, а затем
открывает каждую прямую ссылку и отдельно определяет состояние карточки. Сохраняет
наблюдения, страницы, снимки карточек, причины снятия и замечания менеджеров.

Текущая версия: **0.9.0**. Рабочая папка:
`/Users/filaret/Desktop/a1_search_monitor_noapi_product`.

## Целевое размещение

По решению владельца от 10.09.2026 основная рабочая машина — **MSI с Windows 11,
Intel Core Ultra 5 125U и 16 ГБ памяти**. Главная инструкция:
[установка Windows 11](docs/WINDOWS_11_INSTALL.md). Целевой публичный репозиторий:
[SilverCatSC/A1_Monitoring](https://github.com/SilverCatSC/A1_Monitoring).
Локальный AI-контур основан на Hermes, Q00/Ouroboros, llama.cpp и Qwen3.5-9B;
статический отчёт на GitHub Pages и ссылка на него в Битрикс остаются следующим
этапом. [Устройство AI-контура](docs/AI_AGENTS.md).

Windows-контур подготовлен статически, но живой перенос на MSI и публикация в GitHub
ещё не проверены. Чтобы не повторить перегрузку памяти Mac, Chrome/Docker и локальная
9B-модель выполняются последовательными фазами, а не одновременно.

## Ежедневная работа на Windows 11

1. Запустите Docker Desktop (либо используемый Docker runtime).
2. Откройте PowerShell 7 в папке проекта.
3. Отключите VPN для Auto.ru и Avito.
4. Выполните `.\scripts\run_full_monitoring_windows.ps1`.
5. Наблюдайте за окном Chrome и разделом «Ход текущей проверки». После поисковых
   фильтров появится отдельная стадия `КАРТОЧКИ 1/N`: она последовательно открывает
   прямые ссылки и сохраняет доказательства. Полный прогон стал дольше намеренно.
6. После обхода система сверит найденные и прямые карточки с таблицей маркетинга по VIN, затем
   по ID ссылки для строк без VIN и с учётом статуса «Актуально». Отдельно она
   прочитает публичный каталог `a1auto.ru/cars-for-sale/`: это третья витрина наряду
   с двумя кабинетами Auto.ru и кабинетом Avito. Hermes последовательно проверит
   данные и снимки по одному автомобилю, затем соберёт компактную сводку. Ouroboros
   проверит полноту, доказательства и противоречия, не повторяя всю работу Hermes.
   Результаты появятся в
   `artifacts/company_site_audits/`, `artifacts/head_table_audits/`,
   `artifacts/agent_work_units/`, `artifacts/agent_reviews/` и
   `artifacts/ouroboros_reviews/`.
   Для Avito дополнительно проверяется указание НДС в сохранённом фрагменте описания.
   Отсутствие собственного снимка найденной карточки остаётся отдельным замечанием,
   а не считается подтверждённым результатом.
7. Проверьте «Размещения», «Статистика», затем очередь «Замечания».

Дашборд: [открыть локально](http://127.0.0.1:18000/api/v1/dashboard).
Программа обновляет реестр из таблицы перед каждым обходом. При ошибке импорта
обход не начинается. CAPTCHA решает пользователь; автоматического обхода нет.
Постоянный профиль Chrome хранится отдельно от личного профиля.

С версии 0.9 полный цикл: **импорт → каталоги продавца → сверка ссылок → поисковые
фильтры → прямые карточки → сверка с головной таблицей → сверка каталога A1Auto → Hermes → Ouroboros → отчёт**. При перевыкладке похожие объявления появляются в разделе
«Сверка ссылок», но выбор машины подтверждает человек. Подтверждённая локальная
ссылка защищена от старого значения в таблице. Google Sheets не изменяется.
Неподтверждённые ссылки не образуют серию непоказов. Если продавец недоступен
или запрашивает CAPTCHA, поисковый обход этой площадки не продолжается.

Прямая команда на основном Windows-ПК:

```powershell
Set-Location C:\work\A1_Monitoring
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\run_full_monitoring_windows.ps1
```

`--watch --interval-minutes 360` повторяет импорт и проверку каждые 6 часов после
завершения предыдущего цикла. Компьютер и пользовательская сессия должны работать.
Автозапуск при входе в Windows пока не установлен.

## Интерфейс

| Раздел | Задача |
| --- | --- |
| Обзор | Текущее состояние размещений, проблемы, импорт, ход проверки |
| Автомобили | Все проверяемые машины на одной странице: внешний вид, цена, VIN, год, статус, НДС, выдача и состояние прямых карточек |
| Сверка ссылок | Каталоги продавца, возможные перевыкладки, подтверждение связи с машиной |
| Размещения | Автомобиль × площадка × текущий ID объявления; результаты каждого фильтра |
| Статистика | Доля обнаружений, распределение страниц, дневная история и выходные |
| История проверок | Подробные наблюдения, включая диагностические прогоны |
| Замечания | Ошибки цены, фото, описания; ответственный и подтверждение исправления |
| Активность | Импорты, проверки, изменения реестра, действия менеджеров |
| Настройки | Поисковые фильтры, источники, ручное подтверждение ссылок, диагностика |

Статус «Найдено» в размещениях означает последний положительный результат хотя бы
одного назначенного фильтра в выбранном периоде. Результаты остальных фильтров
раскрываются отдельно. Ссылка на новую публикацию не наследует позицию старого ID.
Старые наблюдения без ID проверяемого объявления остаются в истории, но не
приписываются текущей ссылке. Активные строки головной таблицы, которые не удалось
связать с реестром Monitoring, не скрываются: они выводятся сверху отдельным блоком.

## Где данные

- Реестр, наблюдения, изменения, замечания: PostgreSQL, том `db_data`.
- Скриншоты: `artifacts/evidence/`.
- Логи: `artifacts/manual_scan_*.log` при запуске .command.
- Служебный прогресс: `artifacts/evidence/scan_progress.json`.
- Chrome-профиль: `artifacts/local_chrome_profile/`.
- Резервные копии: отдельный Docker-том `db_backups`.

Не удаляйте Docker-тома для переустановки приложения. Обычный rebuild сохраняет БД.

## Границы измерений

Система измеряет обнаружения в публичном поиске. Просмотры, клики, лиды, расходы
и точную дату публикации объявления она не получает. Отсутствие проверки
отличается от отрицательного результата. Технические ошибки исключены из
знаменателя доли обнаружений. Цена в каталоге — из таблицы; цена при проверке
сохраняется отдельно в наблюдении.

История цены и активности реестра начинается с обновления 0.7.0.
Полнота загрузки выдачи и поведение Zeekr после версии 0.6.3 ещё требуют
контрольного прогона владельца без VPN; обновление интерфейса этого не доказывает.
Для Avito V-Class по-прежнему нужен утверждённый поисковый URL.
